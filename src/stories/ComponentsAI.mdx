# AI Components

Bridge the gap between non-deterministic language models and strict DOM rendering.

Mito's AI interface components are engineered to natively ingest, parse, and render real-time data streams via WebSockets or Server-Sent Events (SSE). 

## Primary Primitives

* **`<AiStreamContainer />`**: A high-throughput wrapper that gracefully handles typing effects, markdown parsing, and latency buffering.
* **`<AgenticPrompt />`**: A dense, resilient input control featuring command-slash logic, multimodal file attachments, and token-count telemetry.
* **`<GenerativeSkeleton />`**: Context-aware loading states that map to anticipated LLM output structures.
